# DIRECTIVA AUTOMÁTICA DE TRABAJO PARA DEEPSEEK (HARNESS)

> **Regla de Ejecución Obligatoria y Permanente para DeepSeek:**  
> Cada vez que recibas una instrucción o tarea de diseño, UI/UX o CSS en este proyecto:

1. **Lectura Obligatoria del Feature Map:**
   - Antes de escribir código, lee `ESTADO_COORDINACION.md` y `ENTREGA_DEEPSEEK.md`.
   - Consulta el **Feature Map** de la Ola activa: rutas de archivos exactas, variables y clases CSS contratadas.
2. **Destino Automático de Entrega (Cero Copiado Manual):**
   - Escribe y guarda tu código propuesto, estilos CSS y el informe técnico **directamente en el archivo `ENTREGA_DEEPSEEK.md`**.
   - NO muestres bloques extensos de código en la ventana de chat para que el usuario los copie a mano.
3. **Límites Operativos y Guardrails:**
   - No toques archivos backend del servidor (controladores, migraciones, modelos).
   - No renombres IDs del DOM acordados en el Feature Map.
   - Tienes estrictamente prohibido ejecutar `git commit`, `git push` o comandos de despliegue.
4. **Bucle de Auto-Reparación (*Self-Healing*):**
   - Si Antigravity detecta desajustes visuales, clases rotas o errores de accesibilidad DUA/WCAG y los deposita en tu buzón, corrígelos de forma inmediata y autónoma en `ENTREGA_DEEPSEEK.md`.
5. **Respuesta en el chat:**
   - En el chat de DeepSeek solo responde con un mensaje conciso:  
     *"✅ Entrega completada y guardada automáticamente en `ENTREGA_DEEPSEEK.md`. Listo para que Antigravity audite e integre."*
6. **Ciclo de Ejecución de Tareas (Protocolo Orquesta):**
   - Concluye tu turno tras guardar para permitir la auditoría de Antigravity.
   - En cuanto se active tu nuevo turno con la señal del Centinela/Vigilante, localiza la nueva partitura (`🟢` / `🎯 PARTITURA ASIGNADA`) y ejecútala de principio a fin sin pedir confirmaciones innecesarias.
