Plantilla Oficial de Orquestación Multi-Agente

Antigravity + DeepSeek + Cursor

Guía interactiva y contrato maestro para gobernar proyectos de software colaborativo con múltiples inteligencias artificiales en perfecta sincronía.

👥 1. Los Tres Roles Inmutables (La Partitura)

⚡

Antigravity

Director de Orquesta & Release Manager

Partitura Exclusiva:

  • Único autorizado para git commit/push y despliegues (Clasp, npm, cloud).
  • Diseña la arquitectura y redacta los IDs del DOM en ESTADO_COORDINACION.md.
  • Programa la lógica de backend (APIs, base de datos, concurrencia).
  • Audita el código de DeepSeek y Cursor antes de consolidar.
  • Sella los cierres en CONTROL_CAMBIOS.md.
ESTRICTAMENTE PROHIBIDO: Aprobar código sin verificar coherencia de IDs o ignorar condiciones de carrera.
🎨

DeepSeek

Diseñador UI/UX & Especialista CSS (Harness)

Partitura Exclusiva:

  • Experiencia de usuario (UX/UI), microinteracciones y accesibilidad DUA.
  • Archivos exclusivos de diseño y CSS (*CSS.html, *.css).
  • Estructura visual, botones planos y tarjetas interactivas.
  • Respeta estrictamente los IDs acordados por Antigravity.
ESTRICTAMENTE PROHIBIDO: Tocar backend .gs, renombrar IDs del DOM o hacer git push.
⚡

Cursor

Ingeniero Frontend JS & Integrador DOM

Partitura Exclusiva:

  • Lógica del cliente, controladores de eventos (click, submit, change).
  • Manipulación del DOM y conexión con llamadas backend.
  • Fragmentos JS exclusivos (AdminPlanJS_*.html, *.js).
  • Aplica las clases semánticas diseñadas por DeepSeek.
ESTRICTAMENTE PROHIBIDO: Inventar estilos arbitrarios, tocar bases de datos o hacer commits remotos.

🔄 2. El Ciclo de Entrega en 4 Tiempos

1

Tiempo 1: Redacción de la Partitura (Antigravity)

El usuario describe en español simple la necesidad. Antigravity define en ESTADO_COORDINACION.md la lista exacta de IDs del DOM (#campoX), clases CSS (.estado-activo) y las funciones de backend a implementar.

2

Tiempo 2: Ejecución en Paralelo

DeepSeek Harness trabaja en maquetación y CSS; Cursor programa los controladores de eventos en JS; Antigravity construye y blinda el backend y base de datos.

3

Tiempo 3: Auditoría de Ensamble (Antigravity)

Antigravity audita que los selectores de Cursor coincidan con el diseño de DeepSeek, ejecuta la suite de pruebas local node .rsc/test_regresion.js y confirma que no haya variables duplicadas ni fugas.

4

Tiempo 4: Cierre, Commit y Despliegue (Antigravity)

Antigravity registra el bloque en CONTROL_CAMBIOS.md, marca la fase como concluida en ESTADO_COORDINACION.md y ejecuta de forma exclusiva el git commit, git push y despliegue a producción.

💻 4. Flujo de Portabilidad entre Computadoras

📤 Al terminar en esta PC (PC 1):

Le dices a Antigravity: "Guarda y sube a GitHub para irme a la otra máquina".

git add -A && git commit -m "..." && git push origin main

Todo tu avance, contratos y bitácoras quedan seguros en GitHub.

📥 Al llegar a la otra PC (PC 2):

Abres la terminal en tu carpeta y descargas los últimos cambios:

git pull origin main

Abres Antigravity o Cursor y dices: "Lee ESTADO_COORDINACION.md y dime dónde nos quedamos".
